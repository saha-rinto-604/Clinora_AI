# Phase 1 Project Initialization

Phase 1 is limited to foundational project initialization.

## Scope

- Repository hygiene files
- Frontend startup shell
- Spring Boot startup shell
- OCR health service
- AI health service
- Docker Compose foundation
- PostgreSQL/RabbitMQ/Redis service definitions
- Empty Spring module package placeholders

## Explicitly Out of Scope

- Registration, login, JWT, roles, and domain authorization
- Domain entities and application tables
- Report upload, OCR processing, AI inference
- Appointments, prescriptions, notifications, blood assistance, research, analytics, dashboards
- Production deployment configuration or real provider credentials
